# 探针 B：几何视图是否是真需求 —— 访谈提纲与结论

**状态：待访谈。** 规范 §6.2 要求访谈 3 位架构师，这需要你来做。下面是访谈提纲，以及要填写的结论。本期不写任何代码。

## 判定规则（规范 §6.2）

- 如果回答集中在"给评审看"：用 **2D 布置图 + 导出** 就够了，不做三维。
- 如果有人确实需要**在模型里推算几何**（比如干涉、线束长度、散热、重量分布），记下具体场景和频率，留给 P4 评估。这类需求通常属于 CAD 或 Cameo 一侧，不在本工具的 L2 定位之内。

## 访谈提纲（每人约 20 分钟）

1. 你现在用什么画物理布置（ECU 在车上的位置、机柜布局、线束走向）？Visio、PPT、CAD 截图，还是别的？
2. 这些图给谁看？评审、供应商、装配，还是你自己做分析用？
3. 为什么要在**架构工具里**画，而不是在 CAD 里？（必问）
4. 图里的位置、尺寸、距离会被**计算**吗（比如线长、重量、温度），还是只用来看？
5. 如果架构工具能做 2D 布置图（块按位置摆放，可以导出 PNG/PDF），能满足你多少？还缺什么？
6. 三维对你意味着什么：只是为了好看，还是确实需要从三维里得到结论？
7. 多久画一次、改一次？由谁维护？
