# ADR 001 事务 身份和启用边界

状态：待目标环境验证。

2026-11-17 本机 SDK 核对：平台 `com.polarion.platform_3.25.12` 的执行环境为 JavaSE-21，`execute().write().callable(...)` 已编译通过。这个结果不包含扩展加载、调用者身份或实际事务行为验证。独立模块应按该目标版本配置，不沿用旧 SSO 模块 release 17 的做法。

选择服务端事务命令扩展，REST 用于读取和附件传输。事务必须覆盖语义工作项、派生链接、幂等记录及模型头；单机 Java 锁、多个 REST 请求、重试和补偿不构成远端原子事务。

沿用经过验证的用户身份，禁止管理员令牌回退。探针默认仅发 GET，不创建工作项、不修改字段、不安装插件、不重启服务。认证凭据由本地文件读入内存，不输出；探针产物只保存状态、能力标志和待验事项。

原子回滚、跨进程并发、扩展调用者权限、结果不明查询与字段保护必须在专用项目实测。在全部通过前，POLARION 模式禁止写入，也不提供可把既有模型切换为新模式的接口。

编码使用 Jackson 生成具有排序字段和映射键的受限 JSON：属性通过 EDataType 的字符串词法表示，数字不是任意 JSON 浮点数。保持文本内容和有序集合原样，区分未设置与已设置的属性；不宣称实现 RFC 8785。业务编号不是 UUID，身份由独立注册表分配并随快照保存。

旧 baseline 快照不作为新存储编码：其忽略 ConstraintExpr、布局和部分包含顺序，不满足全模型无损要求。新增通用 Ecore 编码器，保留旧算法用于现有 LOCAL 基线和差异。
