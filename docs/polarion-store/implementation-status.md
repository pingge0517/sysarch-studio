## 内部基础与边界

- `ModelCodec` 覆盖持久 Ecore 对象、顺序、属性和引用，包括 ConstraintExpr；校验 schema、对象身份、散列和 20 MiB 上限。见 [快照契约](snapshot-format.md)。
- 模型 UUID 与业务编号分离。Liquibase 019 已通过 H2 验证，并在本轮主后端升级时实际应用到 PostgreSQL；未迁移模型数据。
- LOCAL 沿用项目权限及编辑线程，默认行为不变，POLARION 不静默回退本地。
- M2 先检查当前读取权限，再读取语义快照；校验头、清单、快照及元素绑定，拒绝外部需求正文嵌入。历史外部需求真实联调已通过，实际 ACL 修改及全部原生路径仍待后续验收。
- REST 使用调用者 PAT、有限字段、有界附件、响应超时和禁止跳转，不回退服务账号。
- 配置预检仅 GET；字段缺失、类型冲突、不可识别或不可读均判失败。

完整 Sirius representation 布局恢复仍属后续范围；DiagramLayout 编码不等于整图恢复。共享模型快照必须采用一致的全模型读取权限，加载器检查不能替代 Polarion 原生附件访问控制。
