后续已增加已打开页面的授权复核与失效清除，最新见 [读取生命周期验收](M2-read-lifecycle-2026-11-19.md)。以下保留本阶段记录。

## 实现

入口：<http://localhost:3000/polarion-models>。读取模型后选择图根元素，可打开 BDD、IBD、SA、LA、PA 五类只读图，原有分配矩阵、需求追溯矩阵继续可用。

图形使用已安装 Sirius 的公开 `DiagramRepresentation` 组件。后端仍通过原有 VSM 和 `DiagramRenderer` 生成请求内图形；前端适配原生 REST 序列化形状，并使用 ELK 生成本次显示所需的位置。适配复制数据，不修改语义快照；共享节点描述合并子节点类型，避免后出现的实例覆盖前面的定义。

画布具有独立 Apollo 客户端，只在内存中提供图描述查询和图刷新订阅，没有 HTTP 或 WebSocket 传输，不接收 PAT。所有 mutation、未知查询和跨画布引用均被拒绝。`readOnly` 禁止节点拖动，标签不可编辑。组件卸载时停止客户端；凭据、项目、根元素或视图切换会清除旧画布。加载异常显示错误。

每次打开图仍经后端使用调用者 PAT 重新验证模型和依赖读取权限，并比较 subject、version、commitId；画布客户端的 contextId 只是本地渲染标识，不是服务器 Sirius 编辑上下文。
