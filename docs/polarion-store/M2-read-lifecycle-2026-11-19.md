# M2 已打开页面的读取授权生命周期

日期：2026-11-19。入口：<http://localhost:3000/polarion-models>。

## 本轮修改

之前仅在打开模型、矩阵或图时核对权限，已经显示的结果会保留到下一次操作。本轮为结果列表及已打开模型增加限时读取校验：

- 成功显示后，每 20 秒重新读取以检查当前权限；最近一次成功校验的有效期为 30 秒。请求挂起也不会无限延长有效期，到期会中止请求并清除结果。
- 模型复核走原有 snapshot API，重新验证模型元素和需求依赖；subject、version、commitId 变化时清除旧结果，要求重新读取。列表复核发现内容变化也清除旧列表。
- 浏览器发出 offline 事件或页面变为隐藏时，立即清除模型、矩阵、画布及列表；恢复网络或返回页面不会自动恢复旧内容，需要重新读取。
- 清除、账号/项目切换和组件卸载会取消校验、定时器及事件监听；晚到的成功响应不能恢复已清除的数据。读取另一个视图的等待期间仍保留列表校验。

复核仍使用页面内存中的调用者 PAT，GET、同源、无 Cookie、无缓存；未添加服务器持久会话，也未保存 PAT。复核使用完整读取路径，成本随模型大小增长，后续容量验收需测量并优化；不能通过跳过依赖授权来减少开销。
